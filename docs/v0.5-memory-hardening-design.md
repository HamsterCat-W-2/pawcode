# v0.5 持久化记忆管理加固方案

## 目标

在已有用户级、项目级记忆基础上补齐日常维护能力，并让用户能在上下文诊断中确认当前生效的记忆来源。

## 变更

- 新增 `/memory update <id> <内容> [--user|--project]`，保留原 ID 和创建时间，只更新内容与更新时间。
- `/memory` 和 `--show-context` 展示用户级、项目级记忆数量及来源。
- 优先级固定为：基础 system prompt → 用户上下文/用户记忆 → 项目上下文/项目记忆 → 路径规则。项目记忆用于覆盖用户级通用默认值；系统不自动推断语义冲突。
- 所有新增和更新内容继续经过敏感内容过滤；写操作继续经过 `PermissionManager`。

## 验证

- 测试记忆新增、更新、删除、清空和损坏文件容错。
- 测试用户级记忆先于项目级记忆进入上下文，并在 `ContextSource` 中暴露条目数。
- 测试无 `allowWrite` 且无交互确认时记忆写操作被拒绝。
